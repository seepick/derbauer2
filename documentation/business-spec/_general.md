# Story

* you are a king of a kingdom / manage a city
* it is europe in the middle ages, MEDIEVAL theme (oldschool)
* your goal is to expand your kingdom, using production/building/trading/military/...

# User Motivation

* discover/enable new things (features, buildings, tech, military, actions, minigames,...)
    * how about achievements? maybe highscore?
* start small, grow big
    * the UI is almost empty at first; gradually introduce new game features/mechanics/menus/etc.
    * sparkle curiosity to interact with the game, and earn new "things" as a reward
* it's relaxed, no rush (pressure from attackers); difficult to game over

# USP

* the UI and almost all features enable over time; "menu elements can be bought"
    * the game engine and the UI interwoven
* decisions have impact; e.g. turn away beggar and karma decreases; choices shape the future
* everything is interconnected

# Guiding Flavors

* favor interconnectedness
    * everything affects everything
    * every decision has consequences (will be remembered)
* less is more
    * fewer choices, keep it simple (not overwhelm); progress interaction buildup (features unlocked)
    * hide complexity; concepts invisible to player

# Style

* Medieval theme, language more fun (theatralic, fun zynism, old english style)
