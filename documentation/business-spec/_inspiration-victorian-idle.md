# General Notes

* PLAY: https://prod.victorian-idle.com
* game: idle city builder, resource managament, supply chain (production line)
* everything depends on citizen count and needs
    * with new levels, new needs (buildings or resources)
    * forced to build new buildings (have "saturation"/coverage) to get to items to resolve new needs
    * needs can also be protection risks (like fire/crime)
* building:
    * gold upkeep
    * requires workers to work in (like occupying land, but now occupying citizens)
    * production/supply chain: buildings consume/produce things
* additional concepts
    * choose laws, politics; decide on news
        * permanent +/- % boosts for different areas (consumption, production; stats, resources)

# UI description

* main left bar contains:
    * overview: overall info; citizens, resources, ...
    * resources: owned/amount/storage%
    * trade:
        * passive buy/sell, by defining thresholds in %
        * instant buy/sell (10/100 amount)
    * essentials: universally valid buildings + basic buildings
    * for each level (epoch) own button

lvl1 / peasants
=========

* resources:
    * wood/plank
    * fish, potatoe/vodka; cotton/clothes
    * ship sails (ropes)
    * woodcutter -> sawmill
* economical:
    * market: allow for production
    * warehouse, stockpile depot
    * bank
* social:
    * peasant/worker/craftsman/inventor residence
    * pub, music hall (happiness)
    * hospital (health)
    * school, university (tech)
    * church (religion)
    * fire station: probability/risk of fire
    * police station
* food:
    * fish farm, potato planation, vodka distellry
* marina:
    * cotton farm, knift craft hub, shaip sails loft
    * shipyard

lvl2 / workers
========

* resources:
    * stone/brick; coal, iron, steel, steel beam
    * pig/ribs; wheat/flour/bread; herb
* economical:
    * rock deposit, brick factory
    * iron mine, charcoal kiln
    * stellworks, beam factory
    * herb garden, malt house, brewery
* social:
    * worker residence: uses up peasant residence (thus consumes citizens to upgrade them)
* food:
    * pig farm, butchery
    * wheat farm, flour mill, backery
