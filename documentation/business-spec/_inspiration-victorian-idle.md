# General Notes

* everything depends on citizen count
* with new levels, new needs, thus forced to build new buildings to get to items to resolve new needs
    * needs can also be risks, like fire/crime
* building:
    * gold upkeep
    * requires workers to work in (like occupying land, but now occupying citizens)
    * production/supply chain: buildings consume/produce things
